# AI Resume Analyzer

An AI-powered desktop application built with Python and CustomTkinter that analyzes resumes, detects skills, calculates an ATS score, and provides suggestions for improving resume quality.

## 📌 Features

- Upload resumes in PDF and DOCX formats
- Extract and display resume text
- Automatically detect technical skills
- Calculate an ATS (Applicant Tracking System) score
- Generate resume improvement suggestions
- User-friendly graphical interface using CustomTkinter
- Display ATS score using a progress bar

## 🛠️ Technologies Used

- Python
- CustomTkinter
- PDF/DOCX text extraction
- Tkinter
- File Handling
